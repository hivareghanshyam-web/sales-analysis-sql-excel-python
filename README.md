# Sales Performance Analysis using Python, SQL and Excel

## Project Overview
This beginner portfolio project analyses sample sales transactions using Python, Pandas, SQLite SQL, Excel and Matplotlib. It calculates sales KPIs, compares products and regions, explores monthly revenue trends, and creates an Excel workbook with summary sheets.

> **Dataset note:** The included sample sales records are synthetic and created for learning. They are not real company/customer transactions. Do not describe findings as real business impact.

## Objectives
- Inspect data quality, missing values and duplicates.
- Calculate total revenue, order count, units sold and average order value.
- Compare revenue by product, region and month.
- Practise SQL `SELECT`, aggregation, `GROUP BY` and sorting with SQLite.
- Export raw data and summaries to Excel.
- Write evidence-based business recommendations from the output.

## Tools
Python, Pandas, NumPy, Matplotlib, SQLite, Excel, Jupyter Notebook.

## How to Run
1. Download or clone this repository.
2. Install Python 3.10+ and Jupyter Notebook, or open the notebook in Google Colab.
3. Install dependencies: `pip install -r requirements.txt`.
4. Open `notebooks/sales_analysis.ipynb` and run cells from top to bottom.
5. The notebook creates a sample dataset and exports `sample_sales_analysis.xlsx` to the current working directory.
